Common JSON errors this catches

  • Trailing commas: {"a": 1,} — invalid JSON (fine in JS objects).
  • Single quotes: {'a': 1} — JSON requires double quotes.
  • Unquoted keys: {a: 1} — keys must be in double quotes.
  • Comments: // note — the JSON spec allows none.
Error lines: when validation fails, the status shows the parser's error position so you can jump straight to the problem.
