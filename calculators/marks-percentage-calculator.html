Standard grade bands (India)

  • 90%+ — Outstanding / Distinction (top 2–5 percentile usually)
  • 75–89% — First Class with Distinction (merit-list eligible at many boards)
  • 60–74% — First Class
  • 50–59% — Second Class
  • 40–49% — Pass / Third Class
  • Below 40% — typically needs re-attempt (varies by board)
University councils vary. CBSE, ICSE, state boards and universities each publish their own grade cutoffs — check your specific mark sheet rubric.
